一句话：做 2D 网页游戏时，它和 Three.js 共享「AI 最友好」的资格。

In one line: for 2D web games, it shares with Three.js the title of "most AI-friendly".

为什么对 AI 友好

原因说明
TypeScript训练数据最多、且带类型检查 —— AI 写错的概率明显低于其他游戏语言
WebGL/WebGPU跑在浏览器里，不需要装任何东西就能分享
概念少Sprite / Container / Texture —— 不需要学引擎架构
MIT 许可商用无阻碍

Why it is AI-friendly

ReasonExplanation
TypeScriptThe most training data of any language, plus type checking — AI makes noticeably fewer mistakes in it than in other game languages
WebGL / WebGPUIt runs in the browser, so you install nothing to share it
Few conceptsSprite / Container / Texture — no engine architecture to learn
MIT licenceNo obstacle to commercial use

它的代价

  • ⚠ 没有内置物理系统 —— 得自己接（matter.js / planck.js）
  • 没有场景管理 —— 大项目要自己组织
  • 2D only —— 做 3D 得换 Three.js

What it costs

  • ⚠ No built-in physics — you attach one yourself (matter.js / planck.js)
  • No scene management — larger projects need their own organisation
  • 2D only — for 3D you would switch to Three.js

什么时候选它 / 不选

选：2D 网页游戏、快速原型、Game Jam

不选：需要完整引擎功能（碰撞、场景、资源管理都现成）

When to pick it, and when not to

Pick it for: 2D web games, quick prototypes, game jams

Do not pick it if: you need complete engine features out of the box (collision, scenes, asset management)
